## *C - Variables, if, else, while*

___

This repository will focus on Variable, if, else and while functions.

___

Added file `0-positive_or_negative.c`. A C program that assigns a random number to the variable n and prints whether it is positive or negative.\
Added file `1-last_digit.c`. A C program that assigns a random number, and prints the last digit of that number. \
Added file `2-print_alphabet.c`. A C program that prints the alphabet in lowercase. \
Added file `3-print_alphabter.c`. A C program that prints the alphabet in both lower and UPPER case characters.\
Added file `4-print_alphabt.c`. A C program that prints the alphabet, except character `q` and `e`.\
Added file `5-print_numbers.c`. A C program that counts base 10 number. 0-9.\
Added file `6-print_numberz.c`. A C program that prints all single digit numbers of base 10 starting from 0.\
Added file `7-print_tebahpla.c`. A C program that prints the lowercase alphabet in reverse.\
Added file `8-print_base16.c`. A C program that prints all the numbers of base 16 in lowercase.\
Added file `9-print_comb.c`. A C program that prints number from 0 - 9 with a `,` and space inbetween them.
