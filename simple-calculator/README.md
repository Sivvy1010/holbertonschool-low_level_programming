# *WELCOME TO SIMPLE CALCULATOR*

**Note this calculator is made from scratch from my first week learning C Programming at Holberton School**
___
## Scope:
The scope of this task was to create a calculator that has:

- Do not copy code, tutorials, repositories or AI generated.
- A menu with an integer option
- The integer is within the value range
- Only use standard libraries
- math.h is not allowed
- compile using strict compiler flags with zero warnings
- Use basic arithmetic operations such as addition, subtraction, multiplcation and division.
- You are not required to handle non-numeric input (for example: x, hello, 1abc). If the user enters non-numeric input, your program may fail (for example, by looping indefinitely or behaving unexpectedly). This is intentional and accepted at this stage.
___
### Compiling

To compile the `calculator.c` file, please ensure you have gcc installed and use the following command:\
`gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator`

Alternatively you can use the provided file in the repository `calculator` file by using the command:\
`./calculator`.
___
### Requirements
- Print a welcome line
- Display a menu
- Allow quitting with option 0
___
### Limitations

This project has limitations. These are:
- Addition, Subtraction,  Multiplcation and Division will only accept normal integers ***eg 1, 3, 5. Using 3.1 will not be accepted.***
- Division will output a simple float output. 
- Using any other character other than the options provided will end the program.- Using Floats as input will cause the program to loop. ***Press Ctrl+C*** to end the program in such an instance.
